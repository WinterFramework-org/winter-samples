# Domain Docs

이 저장소는 single-context 문서 구조를 사용한다.

## 탐색과 설계
- 루트 GLOSSARY.md가 있으면 읽고, 정의된 도메인 용어를 사용한다.
- docs/adr/에 관련 ADR이 있으면 읽고 설계 결정을 따른다.
- 기존 ADR과 다른 방향을 제안할 때는 충돌과 이유를 명시한다.
- 문서가 아직 없으면 작업을 계속 진행한다.

## 작성
- GLOSSARY.md에는 합의한 도메인 용어와 정의를 기록한다.
- 구현 계획과 기술적 선택은 용어집에 섞지 않는다.
- ADR은 되돌리기 어렵고, 배경 설명이 필요하며,
  실제 대안을 비교해 선택한 결정에 대해 작성한다.
- 용어집과 ADR은 기록할 내용이 생겼을 때 생성한다.
