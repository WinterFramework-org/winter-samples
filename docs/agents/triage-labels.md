# Triage Labels

스킬의 기본 역할을 아래 실제 GitHub 라벨에 연결한다.

| 기본 역할 | 실제 라벨 | 의미 |
|---|---|---|
| needs-triage | needs-triage | 관리자의 평가가 필요함 |
| needs-info | needs-info | 요청자에게 추가 정보를 기다림 |
| ready-for-agent | ready-to-implement | 요구가 충분히 정리되어 에이전트가 구현 가능함 |
| ready-for-human | needs-intervention | 사람의 직접 수행이나 개입이 필요함 |
| wontfix | not-planned | 처리하지 않기로 결정함 |

스킬이 기본 역할명을 사용하면 대응하는 실제 라벨을 적용한다.
